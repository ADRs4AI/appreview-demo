# ADR-0003: Default Label for New Issues

- Status: Proposed

**TL;DR**: New issues currently need a human to notice and label them before anyone picks them up.

## Questions

### QST: Default new issues to Triage, or leave unlabeled?
- Status: unanswered
- Need: yes/no

**Recommendation**: (by Loftsman)

**Yes — default to Triage.** Justification: an unlabeled issue is invisible to every saved search and board this project already uses; Triage costs nothing to remove once a human looks. Consequence if wrong: if Triage itself becomes a graveyard nobody clears, that's a process problem to fix, not a reason to go back to unlabeled.
